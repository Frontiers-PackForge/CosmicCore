# CosmicCore asset notices

This asset namespace contains assets, commonly referred to as "material", under different licenses. Folder location does not override
upstream terms for imported resources. Existing grants remain valid.

- `textures/`: ARR by default with notices for MIT item/block textures and LGPL crop textures.
- `models/`, `shaders/` and `pinwheel/shaders/`: ARR by default and subject to explicit exceptions.
- `.obj`, `.mtl`, `.fsh` and `.vsh` files: ARR by default and subject to explicit exceptions.

Consult the nearest `LICENSE.md` and file specific notice. 
Unlisted resource types receive no new grant from this notice, please reach out if you have any questions.

For CosmicCore owned material, file specific grants take precedence over the nearest folder default.
Generated resources inherit the notice for the same packaged resource path unless strictly noted as otherwise.

License texts: [MIT](../../licenses/MIT.txt), [GPL-3.0](../../licenses/GPL-3.0.txt), and
[CropsNH LGPL-3.0](../../licenses/CropsNH-LGPL-3.0.txt).
[CropsNH provenance](../../licenses/aeroponics/assets.json) records the imported crop textures at the state they were derived from.
