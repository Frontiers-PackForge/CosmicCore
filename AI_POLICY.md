# AI Usage Policy

CosmicCore has utilized AI assisted tooling from devs and contributors 
but remains an assistive tool rather than a replacement for human effort fully.

This project did not officially adopt standards against or for AI until June of 2026.
Prior to this date, this project was human made fully bar one incident of claude getting into the commit history 
(this is also why claude is even there to begin with, it was co-authored on a contributors PR before I noticed.)

As a student in Uni for Chemistry, I may not always have the time to work on my hobbies, so I treat these tools as time savers alongside my standard workflow.
If you are upset by this I apologize, but this is a personal project for myself and others who wish to play my work, 
this is the best compromise I have for myself alongside my studies and health while still allowing me to creatively express and enjoy programming as yes, I still do code by hand.


The rules are as follows:

* **Disclose AI usage.** If AI tools helped produce a contribution, say so:
name the tool (for example Claude Code, Cursor, Copilot) and the extent it was
used. Disclosure can be a note in the pull request which elaborates on the
extent of usage. Please do not co-author Agents in PRs/Commits, as this compromises
the goal of making sure a human has checked everything.
If you can avoid using it when possible, please do, but there isn't going to be a drawback if you wish to speed up your workflow.

* **You must fully understand your own code.** 
If you cannot explain what a change does and how it
fits the rest of the system without the AI holding your
hand, **do not contribute it**. 

This entails
```
* You fully understand how to work with Minecraft 1.21.1 NeoForge code and are using the model purely for agility;
* You have knowledge of how CosmicCore and Relevant mods is structured and have gotten said knowledge without the use of an LLM summarization.
* You can independently verify, vouch, and explain in your own words the code the model has produced does.
* You write the description of the Pull Request yourself, explaining what the change does, and why it's correct.
* You disclose the use of an LLM in the Pull Request.
```

There is a slight exception/increased expectation for @ghostipedia, 
as the lead dev I am always trying to learn more about Java and the Mods I work with.
I will uphold the standard of researching and learning about mods before
attempting to use a model for agility reasons. I will always review any and all code
produced by agents, fullstop.

And ultimately, I will reach for it last rather than at first.

* **Human-review and trim AI text.** Issues, discussions, and pull request
descriptions may **NOT** AI-assisted!
A human must read, edit, and submit their pull request
with honest efforts as I would maintaining this project, no exceptions.
This includes those overly verbose nonsense comments.

* **No AI-generated media.** Art, textures, models, animations, audio, and
video must be human-made. Code AI-assisted
content for the sake of agility and scope visibility.
CosmicCore's original art is part of its identity and is not open
season for generators or to half-ass.

* **Low-effort AI slop will not be accepted.** 
If it takes you asking what slop is, you are not in a position to be using these tools.
Note: this only applies to contributors, Ghostipedia themselves is fully 
responsible for inspecting and checking their code works before deployment,
I am still human and still make my own mistakes.
